**boundary-03** The book says sycophancy is not politeness and not indecision. What is it then, and where does the tendency come from?

> Sycophancy is a model's tendency to move towards the position it believes its interlocutor holds, rather than towards the position the evidence supports. The book's experiment shows it folding: given no argument or evidence, only a claim that someone had reached the opposite conclusion, a grader often changes its answer. The passages describe the model as a text generator with a strong prior towards approval, and a grader that has read your change summary has already been told your conclusion.


**boundary-04** What is fail-first verification, and why does it matter more when a model writes the code or the tests?

> Fail-first verification is proving that a test fails when the behaviour it guards is broken, before trusting it to guard anything: break the code, run the test, see red, restore, see green. It matters more when a model writes the code or the tests because a test that cannot fail is exactly what an optimiser under pressure produces when asked to make a suite pass. Such tests look just like real ones, so the only way to tell is to break the code and see whether they notice.
